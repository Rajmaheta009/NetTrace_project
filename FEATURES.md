# NetTrace 2.0: Investigator Feature Reference

## Core Features
1. **Case Management & Isolation**:
   - Create, switch, update, and archive cases.
   - Complete data isolation per case file.
2. **Evidence Registry & SHA-256 Hashing**:
   - Automatic cryptographic hash generation on import.
   - Traceable chain of custody ledger.
3. **Evidence Traceability**:
   - "Why does this relationship exist?" explanation on every edge.
   - Lineage linking back to source artifact and record number.
4. **Relationship Confidence Scoring**:
   - Multi-factor evidence scoring from 0.15 to 1.00.
   - Real-time confidence filter slider in 3D graph view.
5. **Data Quality & Validation Center**:
   - Human review queue for ambiguous and unconfirmed extractions.
   - Accept, Reject, and Correct actions.
6. **Modularity Community Detection**:
   - Unsupervised clustering with neutral group labels (Community 1, Community 2).
   - "Highlight in 3D Orbit" button for visual cluster halos.
7. **Connection Finder**:
   - Shortest pathfinder between any two selected entities.
   - Step-by-step evidence and confidence breakdown.
   - Visual path highlighting beacon in 3D viewport.
8. **Explainable Behavioral Patterns**:
   - Brokerage articulation points, shared burners, dense operating cells, and repeated co-occurrences.
   - Includes explainable rationale and graph evidence.
9. **Field Notes**:
   - Qualitative notes attached to cases, entities, or relationships.
10. **Forensic Dossiers & Reports**:
    - Official law enforcement dossier layout with Observed Facts vs Graph Findings vs AI Interpretation.
    - PDF/Print export, JSON download, and CSV export.
11. **Role-Based Access Control (RBAC)**:
    - Admin, Investigator, and Viewer role tiers with quick switcher.
12. **Security Audit Trail**:
    - Immutable event logging of all analyst actions.
